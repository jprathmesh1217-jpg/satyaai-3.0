Authentication Protocol Checklist

SPF
Sender Policy Framework

Validates if sending mail server IP is permitted by domain DNS record.

DKIM
DomainKeys Identified Mail

Verifies cryptographic signature to prevent in-transit tampering.

DMARC
Domain-based Message Authentication

Enforces alignment between From header and SPF/DKIM verification results.
